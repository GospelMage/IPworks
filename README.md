# IP Botswana Vanguard — Blockchain Community Network

A corporate, high-end website design and decentralized network portal for **IP Botswana Vanguard** — an energy-light, community-driven blockchain network across Botswana.

## 💎 Features & Visual Identity
- **Visual Design:** Light cream/off-white background (`#FAF8F5`) with Imperial Royal Purple (`#4A2C6D`, `#1F1030`) and Metallic Gold (`#D4AF37`, `#B8860B`) accents.
- **Botswana National Identity:** Prominently integrated Botswana national badges and subtle flag elements (`#5BA8DE` sky blue, black, and white central stripe).
- **Pi Network Ecosystem Synergy:** Dedicated partnership section showcasing Pi Apps, Stellar Consensus Protocol (SCP) compatibility, secure mobile transactions, and BWP/Pi liquidity.
- **Interactive Network Topology:** Real-time HTML5 Canvas simulation rendering consensus packet propagation across 15 district hubs (*Gaborone, Francistown, Maun, Palapye, Kasane, Lobatse, Jwaneng*).
- **Interactive Mobile App Mockup:** 3D styled smartphone UI with real-time simulated block mining counters (`+0.25 IPB/hr`), zero-battery-drain energy indicator (`0.03 kWh/day`), and security circle verification.
- **Sustainability Benchmark:** Comparative table evaluating IP Botswana Vanguard against Bitcoin (PoW) and Ethereum (PoS).
- **Multi-Platform Gateway:** Direct download gateways for Google Play, Apple App Store, Windows 64-bit desktop node validator, and QR code onboarding.

## 🚀 How to Run Locally
Open `index.html` in any modern web browser or run a lightweight local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js / npx
npx serve
```
Then visit `http://localhost:8000` in your browser.
